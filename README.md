# C++ Learning

C++の基礎を学びながら、**自分で設計・実装した簡易RPGバトルゲームを完成させる**ことを目指す学習リポジトリ。

文法を暗記するだけでなく、「なぜこの書き方をするのか」を理解し、自分でコードを書いて動作を確かめることを重視する。

## 開発環境

- Language: C++
- Editor: Visual Studio Code
- Compiler: g++ / macOS の clang
- OS: Windows / macOS
- Version control: Git / GitHub

### RPG制作で練習したこと

- [x] プレイヤー・敵のデータを `struct` で表現
- [x] 攻撃処理・ダメージ計算

現在は、職業に応じて初期攻撃力を設定する小さなプログラムを通して、`enum class`・`switch`・関数の引数と戻り値を学習中。

例：`Warrior` は攻撃力 20、`Mage` は 30、`Thief` は 15 を返す関数を実装した。

## その先の目標：ゲーム開発・VR開発へ

このリポジトリは、ゲーム／VR分野の開発力を身につけるための最初のプロジェクトとして位置づける。

1. **C++：** 基礎と設計を学び、RPGを完成させる
2. **Unity：** C#を使って、小規模でも遊べるゲームを自分で制作する
3. **VR・インタラクティブ技術：** 物理挙動、身体操作、インタラクションなど、関心のあるテーマで試作する
4. **ポートフォリオ：** 各プロジェクトの目的、設計判断、苦労した点、改善内容、実行動画やスクリーンショットを整理し、制作過程を説明できるようにする

まずは目の前のC++ RPGを完成させ、学んだことを実際に動く成果物にする。その後、少しずつゲーム開発・VR開発へつなげていく。

## 学習方針

- 完成コードをそのまま写すのではなく、まず自分で考えて実装する
- 必要なヒントを使い、仕組みを理解してからコードを書く
- 実行結果を確認し、エラーや不具合の原因を自分で探す
- 一度に多くの機能を追加せず、小さく実装して動作確認する
- 学習した内容をRPGに結びつけ、使う理由まで理解する
- 学習が進むたびにこのREADMEを更新し、現在地と次の目標を明確にする

## 最終目標

**自分で設計を考え、複数の機能を組み合わせてゲームを作り、その設計や実装を自分の言葉で説明できるようになる。**

C++で得た基礎を、将来のゲーム開発・VR開発のプロジェクトとポートフォリオにつなげる。
