## 学習方針

### 1. まず自分で書く

新しい機能を学ぶときは、完成コードをそのまま写すのではなく、

1. 仕組みを理解する
2. 小さな問題を解く
3. 自分でコードを書く
4. 実行して確認する
5. 間違いを修正する

という流れで進める。

### 2. RPGを教材として使う

単発の練習問題だけで終わらせず、学んだC++の機能をRPGに組み込む。

例：

- `vector` → 複数の敵を管理
- `struct` → プレイヤー・敵のデータを管理
- `enum` → 職業・属性・行動種類を管理
- `class` → キャラクターや戦闘システムを管理
- `queue` → 行動順などを管理
- ファイル入出力 → セーブ・ロード

### 3. READMEも学習記録として更新する

学習が進んだらチェックリストを更新し、現在地と次の目標が分かる状態を維持する。
